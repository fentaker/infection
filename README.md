# AllumInfection — плагин "Инфекция" для Allum: GO!

## Важное техническое отступление от ТЗ

В ТЗ агрессия заражённых мобов описана как реализация через
"Paper Mob Goal API (NEAREST_ATTACKABLE_TARGET + MELEE_ATTACK)". На практике
публичный API Paper **не позволяет** навесить ванильные голы атаки на моба,
у которого их нет от природы (корова, курица и т.д.) — можно только читать/
удалять уже существующие голы (открытый баг-репорт PaperMC/Paper#12942).
Поэтому агрессия реализована собственным классом `InfectedAIGoal`,
зарегистрированным через тот же самый `MobGoals` API (`Bukkit.getMobGoals().addGoal(...)`),
который даёт идентичное поведение (поиск цели → сближение → атака в ближнем
бою) без обращения к NMS/reflection. Работает на Java и Bedrock (через Geyser)
одинаково, т.к. вся логика считается на сервере.

Все остальные пункты ТЗ реализованы как согласовано.

### Уточнение по Зелью адаптации

Вы подтвердили, что оно "не даёт получать иссушение при контакте с мицелием"
— это дословно про обычного игрока на заражённой земле (п.5 исходного ТЗ). Я
по аналогии распространил это же подавление Иссушения и на **заражённого**
игрока, ушедшего с территории (там Иссушение тоже возникает "от заражения",
просто по другому таймеру) — иначе баф не работал бы ровно для той категории
игроков, которым нужнее всего. Если это не то, что вы имели в виду —
скажите, ограничу баф только сценарием "обычный игрок на территории".

## Сборка .jar (сеть в моей среде исполнения кода недоступна для repo.papermc.io,
## поэтому собрать jar непосредственно я не могу — соберите его сами по инструкции ниже, это займёт 2–3 минуты и не требует знания программирования)

### Вариант А — GitHub Actions (рекомендуется, ничего устанавливать не нужно)

1. Зайдите на github.com, создайте новый **пустой** репозиторий (Public или Private — не важно).
2. Откройте его на вкладке **Code** → **Add file → Upload files**.
3. Перетащите в окно браузера **все файлы и папки** из архива `AllumInfection` целиком (включая скрытую папку `.github`).
4. Нажмите **Commit changes**.
5. Перейдите на вкладку **Actions** — там автоматически запустится сборка ("Build plugin"). Подождите, пока появится зелёная галочка (1–2 минуты).
6. Откройте этот запуск, внизу страницы будет раздел **Artifacts** → скачайте `AllumInfection-jar` (это zip, внутри — `AllumInfection.jar`).

### Вариант Б — локально, если у вас есть компьютер с интернетом

1. Установите **JDK 25** (Adoptium Temurin) и Apache Maven.
2. В папке проекта выполните: `mvn package`
3. Готовый файл появится в `target/AllumInfection.jar`

### ⚠️ Важно про версию Java

Артефакт `paper-api:26.2.build.107-stable` скомпилирован под **Java 25**
(class file version 69), а не Java 21. Это значит, что и сам сервер Paper
26.2 build 107 требует для запуска **JDK 25**, а не JDK 21. Если ваш сервер
сейчас реально запущен на JDK 21 — он либо не стартует на этом билде Paper,
либо у вас установлен более старый билд. Проверьте версию Java на сервере
(`java -version`) и при необходимости обновите её до 25 — иначе даже
собранный правильно `.jar` не загрузится.

## Установка на сервер

1. Остановите сервер.
2. Скопируйте `AllumInfection.jar` в папку `plugins/`.
3. Запустите сервер — при первом старте создастся `plugins/AllumInfection/config.yml`.
4. Если сервер откажется загружать плагин из-за несовпадения версии API — откройте `plugin.yml` внутри jar (или пересоберите из исходников), исправьте строку `api-version: '1.21'` на версию вашего конкретного билда Paper 26.2 и пересоберите.

## Команды и права

Право: `allum.infection.admin` (по умолчанию — только OP)

| Команда | Действие |
|---|---|
| `/infection tool` | выдать жезл заражения (палка) |
| `/infection stop` | пауза распространения по блокам |
| `/infection resume` | снять паузу |
| `/infection kill` | полный сброс: блоки восстановлены, заражённые мобы удалены |
| `/infection info` | статус, кол-во заражённых блоков, текущий интервал, живые заражённые мобы |
| `/infection time <минуты>` | меняет интервал цикла распространения (переживает рестарт) |
| `/infection cure <игрок>` | снимает заражение с игрока (нужно, чтобы игрок был онлайн) |

## Как это работает

### Распространение по блокам
- ПКМ жезлом по блоку — ставит первый очаг (мицелий). С этого момента раз в
  `interval` минут заражается 2 случайных блока в радиусе 2 от случайного
  уже заражённого блока. Интервал теперь настраивается на лету командой
  `/infection time <минуты>` (по умолчанию — из config.yml).
- Огонь/лава на заражённом блоке — через 5 сек возвращает конкретно этот
  блок в исходный материал.

### Заражённые мобы
- Любое живое существо (кроме игроков), вставшее на заражённый блок,
  заражается: переименовывается, теряет весь ванильный ИИ (в т.ч. агрессию у
  изначально враждебных мобов вроде зомби/скелета) и получает собственный ИИ
  атаки — атакует всех незаражённых 5 минут, затем умирает (обычный дроп +
  гриб), на месте смерти появляется мицелий.

### Грибная цепочка крафта → заражение игрока
1. **Грибовик**: в верстак 9 грибов (красных/бурых, любая комбинация) → 1 Грибовик.
2. **Грибная спора**: в верстак 9 Грибовиков → 1 Грибная спора.
3. Съесть Грибную спору → игрок **заражается**: не атакуется заражёнными
   мобами (даже изначально враждебными), на мицелии всегда получает Сытость I
   + Скорость I. Вне заражённой земли — сразу Слабость II + Голод II, через
   60 сек добавляется Иссушение II. Заражённый игрок, убивший моба, оставляет
   под ним мицелий (как и заражённые мобы).
4. Излечиться можно командой `/infection cure` или **умерев от огня/лавы**
   (другие причины смерти заражение не снимают).

### Зелье адаптации
- В зельеварку: 3 бутылки **Мутного зелья** + **Грибная спора** сверху,
  топливо (бластер-порошок) — варится 10 минут → 3 Зелья адаптации
  (обычное/на разбитие/долгоиграющее — рецепт работает для всех трёх видов).
  **Важно:** это не ванильный рецепт зельеварения — зельеварка используется
  только как контейнер, всю варку (проверку условий, отсчёт времени,
  результат) ведёт сам плагин (`CustomBrewManager`), поэтому визуально
  зельеварка не показывает стандартную пузырящуюся стрелку прогресса —
  вместо этого при старте и завершении варки проигрываются свои
  звук/партиклы. Открывайте инвентарь зельеварки, чтобы увидеть, идёт ли
  сейчас варка (спора и зелья на месте — значит, идёт).
- Выпитое (или попавшее по игроку через сплэш/облако) Зелье адаптации даёт
  5 минут **адаптации**: Иссушение от заражённой земли не действует, Голод —
  по-прежнему действует. Зельем на разбитие/долгоиграющим можно "поделиться"
  адаптацией с другим игроком.
- Все три новых предмета — на ванильных текстурах (Ножка гриба, Ядовитая
  картошка, обычное зелье), различаются только именем/лором, поэтому
  корректно отображаются на Bedrock через Geyser. Грибная спора специально
  сделана на съедобном материале (иначе ПКМ по ней не запускает поедание —
  так и было с первой версией на Спороцвете, это баг, теперь исправлено).
  **Не кладите Грибовик как блок в мир** — Ножка гриба технически ставится,
  но при этом теряет метку и превращается в обычный ванильный блок.

### Игроки (не заражённые)
- На заражённой территории получают Голод I сразу и Иссушение I через 60 сек;
  эффекты держатся ещё 10 сек после выхода. Зелье адаптации подавляет
  Иссушение и для них тоже (Голод остаётся).

### Прочее
- Все параметры (радиус, тайминги, шансы грибов, урон от Иссушения, время
  варки, длительность бафа) настраиваются в `config.yml` без пересборки.
- Состояние переживает рестарт сервера (файл `infection-data.yml` в папке
  плагина: заражённые блоки + интервал); статус заражения игрока хранится
  прямо в данных игрока и тоже переживает рестарт. Заражённые мобы и баф
  адаптации — нет (мировые сущности и временный баф не персистентны).
